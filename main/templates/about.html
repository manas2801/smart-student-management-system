About This Project

Smart Student Management System is a premium web application built using Django. It is designed to simplify academic and administrative tasks by providing one integrated platform for student records, attendance, marks, fees, assignments, notices, timetable, role-based access, and analytics.

Frontend

HTML, CSS, modern layout design, premium cards, tables, and animations.

Backend

Python Django framework for business logic, views, routing, and authentication.

Database

SQLite database used for storing student, attendance, marks, fees, and notices.

Architecture

Django MVT architecture: Model, View, and Template.
